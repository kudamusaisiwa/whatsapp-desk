Desk AI for WhatsApp Web

An AI reply assistant inside WhatsApp Web. Connect your own provider API key and business information.

Start with drafts you review. Automatic sending is off when you first install.

1. Install in Chrome

  1. Download WhatsApp-Desk.zip and unzip it.
  2. Keep the extracted WhatsApp Desk folder somewhere permanent, such as Documents.
  3. Open chrome://extensions in Chrome and turn on Developer mode.
  4. Click Load unpacked and select this folder inside the unzipped download:

    WhatsApp Desk/releases/WhatsApp-Desk

    Open WhatsApp Desk, then releases, then select WhatsApp-Desk.
  5. Open or refresh WhatsApp Web. Your assistant appears on the right.

On Mac, double-click the ZIP. On Windows, right-click → Extract All. Use the named WhatsApp-Desk.zip release download; Source code downloads are for developers.

“Manifest file is missing or unreadable”? Click Cancel, then Load unpacked again and select WhatsApp Desk/releases/WhatsApp-Desk.

Keep Developer mode on and keep the extracted folder. No coding is needed. Requires desktop Chrome 120 or later; managed work browsers may need IT approval.

2. Connect your own provider

  1. Choose OpenAI, OpenRouter, Kimi (Moonshot), DeepSeek, Anthropic, Google Gemini or xAI Grok. Create your own API key using that provider's official account dashboard and set up its API billing.
  2. In Desk AI for WhatsApp Web, open Settings, select a provider for a task, enter your key and save the connection.
  3. Refresh the provider's model list and select a model compatible with the task, or enter an exact model ID. Set routes independently for replies/general assistant, image understanding, polish, call summaries, dictation and call transcription.

No key is included. Providers bill API usage under their own terms; OpenAI API billing is separate from a ChatGPT subscription. Desk AI does not currently offer Sign in with ChatGPT or ChatGPT-plan inference. Model capabilities vary. OpenAI, OpenRouter and Gemini speech transcription are available; other providers do not currently support speech-to-text in Desk AI. Images need a compatible image-input model. Image generation and speech audio (TTS) are not included. See provider details.

3. Make it yours

  1. In Settings, enter your business name, set your reply style and match the date order shown in WhatsApp. Save your settings.
  2. In Knowledge, upload your services, prices, hours, policies and FAQs, or write a business note. PDF, DOCX, TXT, Markdown, CSV and JSON are supported. Scanned PDFs need OCR first.
  3. Open an individual chat and click Draft a reply. Review or edit the draft in WhatsApp, then send it yourself.

The library starts empty. No sender’s keys, business files, chats, notes or follow-ups are included. Auto-send, Draft as messages arrive and Reply across all chats start off. Enable them later only when you are happy with your drafts.

4. Know where your data goes

Your provider keys, business library, notes and follow-ups stay in this browser profile. Keys are not synced or exposed to the WhatsApp webpage. Local storage is not independently encrypted: someone with access to the browser profile or extension developer tools may access them. Remove saved keys in Settings.

When you run an AI task, only the data needed for that task is sent from the trusted extension worker to the selected provider: drafts can include relevant business excerpts, recent visible chat messages and included pictures; polishing sends only selected text; summaries send the transcript and names you provide; transcription sends audio only after you start it. Provider privacy and retention terms apply. The extension does not send AI content to the licensing service.

Keep Chrome running, the computer awake and WhatsApp signed in for timely reminders and automation. All-chat mode watches the newest visible inbox rows. Removing the extension clears its local data.

Need a hand?

Manifest missing? Select WhatsApp Desk/releases/WhatsApp-Desk inside the unzipped release.

No panel? Check the extension is enabled, then refresh WhatsApp Web. Key or model error? Check that provider's API access and refresh the model list. Missing answers? Add your own information in Knowledge.

For full troubleshooting, everyday limits and update instructions, open START-HERE.txt. Read the provider and model guide for data routing and current capability limits.

To update, replace files in the same installed folder, click Reload on Desk AI for WhatsApp Web's Chrome extensions card and refresh WhatsApp. Avoid removing it if you want to keep local data.
