WhatsApp Desk

An AI reply assistant inside WhatsApp Web. Set it up in Chrome with your own OpenAI API key and business information.

Start with drafts you review. Automatic sending is off when you first install.

1. Install in Chrome

  1. Extract WhatsApp-Desk.zip. Use the named release download, rather than GitHub’s Source code (zip). On Windows, right-click → Extract All. On Mac, double-click.
  2. Move the extracted WhatsApp-Desk folder somewhere permanent, such as Documents. Keep it there.
  3. In Chrome’s address bar, type chrome://extensions and press Enter.
  4. Turn on Developer mode at the top right, then click Load unpacked.
  5. Select the WhatsApp-Desk folder containing manifest.json. Select the folder, not the ZIP. If there is an extra outer folder, open it to find the inner one.
  6. Open WhatsApp Web and sign in. Refresh an existing WhatsApp tab. Your assistant appears on the right.

Keep Developer mode on. No coding or terminal commands are needed. Requires desktop Chrome 120 or later; managed work browsers may need IT approval. The toolbar button opens or collapses the panel.

2. Connect your own key

  1. Create your own secret key on the OpenAI API keys page. Set up API billing in your OpenAI account.
  2. In WhatsApp Desk, open Settings, paste your key and click Save key & connect.
  3. Refresh the model list, select a compatible model available to your project and click Save workspace settings. The model must support Responses and structured output; pictures also need image input.

Currently supports OpenAI keys only. No key is included. API usage is billed separately from ChatGPT.

3. Make it yours

  1. In Settings, enter your business name, set your reply style and match the date order shown in WhatsApp. Save your settings.
  2. In Knowledge, upload your services, prices, hours, policies and FAQs, or write a business note. PDF, DOCX, TXT, Markdown, CSV and JSON are supported. Scanned PDFs need OCR first.
  3. Open an individual chat and click Draft a reply. Review or edit the draft in WhatsApp, then send it yourself.

The library starts empty. No sender’s keys, business files, chats, notes or follow-ups are included. Auto-send, Draft as messages arrive and Reply across all chats start off. Enable them later only when you are happy with your drafts.

4. Know where your data goes

Your key, business library, notes and follow-ups stay in this browser profile. Keys are not synced or exposed to the WhatsApp webpage. Local storage is not independently encrypted: someone with access to the browser profile or extension developer tools may access it. Use Settings → Remove saved key to clear the key.

AI drafting sends relevant business excerpts, recent visible chat messages and any included pictures directly to OpenAI. Your key authenticates these requests. There is no hosted app backend or analytics. Requests use store: false; OpenAI’s own API data policies still apply.

Keep Chrome running, the computer awake and WhatsApp signed in for timely reminders and automation. All-chat mode watches the newest visible inbox rows. Removing the extension clears its local data.

Need a hand?

Manifest missing? Select the extracted folder with manifest.json directly inside it. If you built from developer source, select its dist folder. The source project root cannot be loaded as an extension.

No panel? Check the extension is enabled, then refresh WhatsApp Web. Key or model error? Check your API billing and refresh the model list. Missing answers? Add your own information in Knowledge.

For full troubleshooting, everyday limits and update instructions, open START-HERE.txt.

To update, replace files in the same installed folder, click Reload on its Chrome extensions card and refresh WhatsApp. Avoid removing it if you want to keep local data.
