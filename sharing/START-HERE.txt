DESK AI FOR WHATSAPP WEB — START HERE
Chrome extension • Version 0.5.2 • Bring your own provider API key

1. INSTALL IN CHROME

1) Download WhatsApp-Desk.zip and unzip it:
   https://github.com/kudamusaisiwa/whatsapp-desk/releases/latest/download/WhatsApp-Desk.zip
2) Keep the extracted WhatsApp Desk folder somewhere permanent, such as Documents. The extension is named Desk AI for WhatsApp Web inside Chrome.
3) Open chrome://extensions in Chrome and turn on Developer mode.
4) Click Load unpacked and select this folder inside the unzipped download:

   WhatsApp Desk/releases/WhatsApp-Desk

   Open WhatsApp Desk, then releases, then select WhatsApp-Desk.
5) Open or refresh https://web.whatsapp.com. Desk AI for WhatsApp Web appears on the right.

On Mac, double-click the ZIP to unzip it. On Windows, right-click > Extract All.
Use the named WhatsApp-Desk.zip release download; Source code downloads are for developers.
Keep Developer mode on and keep the extracted folder. No coding is needed.
Requires desktop Chrome 120 or later; managed work browsers may need IT approval.

If Chrome says "Manifest file is missing or unreadable", click Cancel and
Load unpacked again, then select WhatsApp Desk/releases/WhatsApp-Desk.

2. CONNECT YOUR OWN OPENAI KEY

1) Choose one of the supported providers: OpenAI, OpenRouter, Kimi (Moonshot),
   DeepSeek, Anthropic, Google Gemini or xAI Grok. Create your own API key
   through that provider's official account dashboard.
2) Set up API access and billing with that provider. API usage is billed by
   the provider/account owner. OpenAI API billing is separate from a ChatGPT
   subscription; this extension does not include ChatGPT-plan access.
3) In Desk AI for WhatsApp Web, open Settings, choose a provider for the task,
   enter your key and save the connection.
4) Refresh that provider's model list. Pick a model compatible with the task,
   or enter its exact model ID. Set routes independently for replies/general
   assistant, images, polish, call summaries, dictation and call transcription.

No provider key is supplied. Never send your secret key to the person who
gave you this ZIP. Keys are saved in this extension's local browser storage,
are not synced or exposed to the WhatsApp webpage, and are sent only to the
selected provider for requests. They are not independently encrypted: someone
with access to your browser profile or extension developer tools may access
them. Remove saved keys in Settings.

Model compatibility varies. OpenAI, OpenRouter and Gemini transcription
adapters are available. Other providers do not currently support speech-to-
text in Desk AI. Image understanding requires a model with image input. Image
generation and text-to-speech are not included. See
https://github.com/kudamusaisiwa/whatsapp-desk/blob/main/docs/ai-providers.md
for current provider details and limitations.

3. ADD YOUR BUSINESS

1) In Settings, replace Your business with your business name.
2) Set your assistant's reply style. Match the date order to the dates shown
   in WhatsApp, then click Save workspace settings.
3) In Knowledge, upload your business information or write a note: services,
   prices, opening hours, policies, contact details and FAQs. Supported files:
   PDF, DOCX, TXT, Markdown, CSV and JSON. Scanned PDFs need OCR first.
4) Open a one-to-one chat and click Draft a reply. Review the draft in the
   WhatsApp message box, edit it if needed, then send it yourself.

The business library starts empty. No sender's business knowledge, saved
keys, customer conversations, notes or follow-ups are included in this ZIP.
Auto-send, Draft as messages arrive and Reply across all chats start OFF.
You can enable these controls later after checking your own drafts.
Only enable automatic sending when you are happy for replies to send without
review. A reply flagged for human review still stays as a draft.

4. PRIVACY AND EVERYDAY USE

AI drafting sends relevant business knowledge and recent visible chat messages
to the provider selected for that task. Drafts can include relevant business
excerpts, recent visible chat messages and loaded photos/screenshots. Polishing
sends only selected text; call summaries send transcript and supplied names.
Audio is sent for transcription only after you start that action. The recipient
must be comfortable using that provider with business and customer
information. Each provider's data and retention terms apply. The extension
does not send AI content to the licensing service and has no advertising
analytics.

Keys, knowledge, client notes and follow-ups stay in this browser profile.
Removing the extension removes its local data. Chrome must be running and
the computer awake for timely automation/reminders. Keep WhatsApp signed in.
All-chat mode watches the newest visible inbox rows; keep the All inbox at
the top for coverage. It does not scan the complete account history.
For screenshots/photos, open or download them in WhatsApp if needed.
Voice notes, videos and document attachments from chats are not read.
This is an independent assistant, not an official Meta/WhatsApp product.

5. IF SOMETHING DOES NOT WORK

- No panel: check the extension is enabled at chrome://extensions, then
  refresh WhatsApp Web. Collapse/expand it with its Chrome toolbar button.
- Cannot find manifest.json: unzip WhatsApp-Desk.zip, click Load unpacked and
  select WhatsApp Desk/releases/WhatsApp-Desk.
- Key rejected: check that provider's account access, billing and key, then reconnect in Settings.
- Usage/rate limit: check your API billing, credits and project limits.
- Model unavailable: refresh the model list and choose a compatible model.
- Generic or missing answers: add your own approved documents in Knowledge.
- Interface changed: WhatsApp changes can require an extension update.

UPDATING
Keep the same installed folder and replace its files with the new version.
At chrome://extensions, click Reload on Desk AI for WhatsApp Web, then refresh WhatsApp.
Avoid removing/reinstalling if you want to retain the extension's local data.
